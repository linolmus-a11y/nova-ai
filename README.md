# NOVA Web

Полноценный веб-интерфейс AI-ассистента: чат, история в браузере, адаптивный дизайн и серверная интеграция с OpenAI Responses API.

## Запуск

Требуется Node.js 18+.

1. Скопируй `.env.example` в `.env`.
2. Вставь свой API key.
3. Выполни:
   `npm install`
   `npm start`
4. Открой `http://localhost:3000`.

API key находится только на сервере и не попадает в браузер.

## Публикация

Для публичного сайта нужен хостинг Node.js/контейнер. Переменную `OPENAI_API_KEY` задавай через секреты хостинга, а не в клиентском JavaScript.

Для реального публичного сервиса рекомендуется добавить авторизацию, rate limiting, базу данных, лимиты расходов, логи, CSRF/CORS-настройки и модерацию.
